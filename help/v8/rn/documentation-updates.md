# Aggiornamenti alla documentazione {#latest-updates}

In questa pagina sono elencati tutti gli aggiornamenti della documentazione di Adobe Campaign Web.

## Giugno 2026 {#june-2026}

* È stata aggiunta una nota sui requisiti di codifica per le consegne direct mail destinate alle lingue CJK (giapponese, coreano, cinese semplificato, cinese tradizionale). La codifica predefinita Latin-1 (1252) non può rappresentare caratteri CJK, comportando una visualizzazione di un’anteprima del file vuota. Gli utenti devono selezionare UTF-8 (65001) nelle impostazioni del formato di estrazione. [Ulteriori informazioni](../direct-mail/content-direct-mail.md)
* È stata aggiunta una pagina sulle linee guida CNIL sui pixel di tracciamento delle e-mail e alle relative funzionalità di Adobe Campaign. [Ulteriori informazioni](https://experienceleague.adobe.com/it/docs/campaign/campaign-v8/new/cnil-pixel-tracking){target="_blank"}

## Dicembre 2025 {#december-2025}

**Data: 1 dicembre 2025**

* È stata riorganizzata la guida alla documentazione di Genera contenuti con pagine consolidate per [generazione di contenuti completi](../content/generative-full-content.md), la [generazione di testo](../content/generative-text.md) e la [generazione di immagini](../content/generative-image.md)
* È stata aggiunta la [guida alle best practice per i prompt di Genera contenuti](../content/ai-assistant-prompting-guide.md) per aiutare gli utenti a creare prompt efficaci
